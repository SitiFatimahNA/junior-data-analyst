## ⭐ Final Project: Marketing Campaign Analysis

Project akhir yang mengintegrasikan seluruh proses analisis data secara end-to-end, dari pemahaman business problem hingga dashboard dan rekomendasi bisnis.

| Item | Link/Keterangan |
|---|---|
| 🎥 **Video Dokumentasi** | [Tonton di YouTube](https://www.youtube.com/watch?v=PY1Uyx_O37Y) |
| 📁 **Folder Project** | [`/projects/final-project-marketing-campaign-analysis`](./projects) |
| 📊 **Dataset** | ifood_df.csv (2.021 baris setelah cleaning, 39 kolom) |
| 🛠 **Tools** | Python (Pandas, Matplotlib, Seaborn), Microsoft Excel |

**Ringkasan singkat:**
Menganalisis efektivitas marketing campaign perusahaan berdasarkan data pelanggan, menemukan bahwa customer dengan recency rendah (baru bertransaksi) dan tanpa anak jauh lebih responsif terhadap campaign, serta mengidentifikasi kesenjangan performa yang lebar antar-campaign historis. Hasil analisis dirangkum dalam project charter, laporan EDA, root cause analysis, dashboard interaktif, laporan akhir, dan presentasi.

**Deliverables:**
- ✅ Project Charter
- ✅ Data Cleaning Log
- ✅ EDA Report (11 visualisasi + insight)
- ✅ Root Cause Analysis & Recommendation Matrix
- ✅ Dashboard Interaktif (Excel)
- ✅ Final Analysis Report
- ✅ Presentation Deck
- ✅ Portfolio Summary
